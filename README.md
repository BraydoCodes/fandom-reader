# fandom-reader
A tool that allows you to extract desired information from a fandom page of your liking. This allows you to target certain elements to grab the contents of only what you need!

---

## How to use
The tool will prompt you through a set of instruction, please read these carefully.

This project assumes that you have chromium install on your computer, to downloaded the required packages use `pip3 install -r requirements.txt`
